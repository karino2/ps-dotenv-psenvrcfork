# Clear-Dotenvrc

## SYNOPSIS
Clear all approved info and unload all variables.

## SYNTAX

```
Clear-Dotenvrc
```

## DESCRIPTION
Clear all approved files info and unload all environment variables loaded by .psenvrc.

## EXAMPLES

### Example 1
```powershell
PS C:\> Clear-Dotenvrc
```
